# Lincoln Home AR Prototype

A web-based augmented reality prototype built with [AR.js](https://ar-js-org.github.io/AR.js-Docs/) for Lincoln Home National Historic Site in Springfield, Illinois.

This is an independent research prototype by Sepehr Vaez Afshar (University of Illinois Urbana-Champaign). It is not a National Park Service product.

## Status

This repository currently holds the project description only. Prototype files will be added here.
